# CV Maker Application
- A simple CV maker app which let the user curate the cv form with their own desired data.
- It uses default popular cv format which is widely used in the industry.
- It lets user add multiple education and experience cards.
- It has a print button which lets the user instantly print / download the cv in their own desired format.

# To Run It Locally 
### Prerequisites: 
- you need to have react setup in your local computer.
### Follow step by step: 
- First open the command prompt and cd to the folder you want to create the cv-app folder.
- Run `git clone https://github.com/Shubham277353/cv-application.git` , which will create a new directory in your current location.
- next do `cd cv-application` and open with vs code.
- finally in the command prompt do `npm install` to install all the dependencies.
- To run the project use `npm run dev`.
